# infra

Инфраструктура развёртывания: reverse-proxy, контейнеры и конфигурация
окружений.

## Сейчас

Развёртывание локальное. `pnpm dev` запускает два процесса:

- `apps/web` — Next.js на `:3000`;
- `apps/api` — Hono + WebSocket на `:4000`.

Браузер ходит в `/api/*` на веб-оригин, Next проксирует запросы в API.
Плеер подключается к `ws://localhost:4000/ws/device` напрямую.

## Дальше

На Фазе 5 появится один публичный origin: Caddy (или другой reverse-proxy)
будет отдавать веб, API и WebSocket с одного домена и TLS.

Ориентировочная схема:

```text
/            -> apps/web:3000
/api/*       -> apps/api:4000
/ws/*        -> apps/api:4000   (Upgrade: websocket)
```

Для такой схемы понадобятся:

- `PUBLIC_URL` — публичный адрес веба;
- `API_PUBLIC_URL` — публичный адрес API;
- `NEXT_PUBLIC_WS_URL` — `wss://<домен>/ws/device`;
- `API_INTERNAL_URL` — внутренний адрес API для Next rewrite.

Caddyfile, контейнеры и упаковка появятся вместе с этой фазой. Сейчас
в каталоге нет рабочей конфигурации, чтобы не создавать ложное впечатление,
что проект уже готов к продакшену.
