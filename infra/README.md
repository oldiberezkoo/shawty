# infra

Инфраструктура развёртывания: reverse-proxy, контейнеры, конфигурация
окружений.

Пока не используется: на Фазе 0 запуск локальный, двумя процессами
(`apps/web` и, позже, `apps/api`). Caddyfile и упаковка появятся на Фазе 5,
когда понадобится один публичный origin для cookie, CSRF и WebSocket.
