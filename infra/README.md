# infra

`INFRA` · `REVERSE-PROXY` · `ФАЗА 5`

Инфраструктура развёртывания: reverse-proxy, контейнеры и конфигурация
окружений. Сейчас развёртывание локальное; продакшен-конфигурации ещё нет.

---

## `[01]` Сейчас

`LOCAL` · `:3000` · `:4000`

`pnpm dev` запускает два процесса:

| `ПРОЦЕСС` | `ЧТО ЭТО` |
|---|---|
| `apps/web` | Next.js на `:3000` |
| `apps/api` | Hono + WebSocket на `:4000` |

Браузер ходит в `/api/*` на веб-оригин, Next проксирует запросы в API.
Плеер подключается к `ws://localhost:4000/ws/device` напрямую.

---

## `[02]` Дальше

`PHASE 5` · `TLS` · `ONE ORIGIN`

На Фазе 5 появится один публичный origin: Caddy (или другой reverse-proxy)
будет отдавать веб, API и WebSocket с одного домена и TLS.

```text
/            -> apps/web:3000
/api/*       -> apps/api:4000
/ws/*        -> apps/api:4000   (Upgrade: websocket)
```

| `ПЕРЕМЕННАЯ` | `ЗАЧЕМ` |
|---|---|
| `PUBLIC_URL` | Публичный адрес веба |
| `API_PUBLIC_URL` | Публичный адрес API |
| `NEXT_PUBLIC_WS_URL` | `wss://<домен>/ws/device` |
| `API_INTERNAL_URL` | Внутренний адрес API для Next rewrite |

Caddyfile, контейнеры и упаковка появятся вместе с этой фазой. Сейчас в
каталоге нет рабочей конфигурации, чтобы не создавать ложное впечатление, что
проект уже готов к продакшену.

## `[03]` Дизайн и статика

`NEXT/FONT` · `SVG` · `CANVAS`

Дизайн-система живёт в вебе и не требует внешних ассетов:

| `ЧТО` | `КАК ОТДАЁТСЯ` | `ЧТО УЧЕСТЬ` |
|---|---|---|
| Шрифты Geist и Geist Mono | `next/font` скачивает их на сборке и отдаёт из `/_next/static` | Первая сборка требует сети; в рантайме внешних запросов нет |
| Знак и иконки | Инлайновые SVG-path | Ничего не нужно класть в CDN; работают в офлайновом киоске |
| Дизеринг-сцены | Canvas, палитра из CSS-переменных | Изображений нет; смена темы перекрашивает сцену без перезагрузки |
| Медиа | API (`/api/dashboard/media/file`) с `Range` | Прокси не должен буферизовать ответ и ломать `Range` |
| Тема | Класс `.dark` на `<html>`, выбор в `localStorage` | Один HTML годится для обеих тем; сервер не рендерит вариант по теме |

- `/_next/static` — долгий кэш и `immutable`; proxy не должен переписывать
  эти пути.
- `/ws/*` — обязательный `Upgrade: websocket` и таймауты больше интервала
  heartbeat, иначе прокси будет рвать соединение первым.
- Если появится CSP, инлайновый скрипт темы в `<head>` потребует `nonce` или
  хэш; иначе страница применит тему после первой отрисовки и мигнёт.
