# apps/web

Веб-приложение SHAWTY: публичный лендинг, панель управления и плеер на
телевизоре. Здесь же живёт дизайн-система продукта — остальные приложения
только поставляют данные.

## Запуск

Из корня репозитория:

```bash
pnpm install
pnpm db:migrate
pnpm db:seed
pnpm dev                 # API :4000 + веб :3000
```

Отдельно веб:

```bash
pnpm --filter @shawty/web dev
```

Проверки:

```bash
pnpm --filter @shawty/web typecheck
pnpm --filter @shawty/web build
pnpm check               # типы, тесты API и production-сборка веба
```

`apps/web` не ходит в базу и не импортирует код API. Данные приходят по HTTP
через `/api/*` (Next проксирует запросы в API), общие типы — из
`@shawty/contracts`. Границы слоёв описаны в
[`ARCHITECTURE.md`](./ARCHITECTURE.md).

## Дизайн-система

Источники правды:

- `src/app/globals.css` — токены, темы и базовые классы. Единственный
  глобальный CSS; всё остальное набирается утилитами Tailwind поверх токенов.
- [`design.md`](./design.md) — справочник системы: палитра, типографика, сетка,
  компонентные паттерны, пиксельная графика, правила анимации.
- `src/components/ui` — примитивы и паттерны без знания о домене.
- `src/components/visual` — знак, пиксельные иконки, дизеринг-сцены, окно.

Справочник собран по исходному сайту семейства продуктов (там заголовки
набраны Switzer). В SHAWTY принципы те же, но заголовки и текст — **Geist**, а
служебные строки — **Geist Mono**; светлая тема не только документирована, но и
рабочая.

### Принципы

1. **Квадратные углы.** Радиусы отключены глобально: `border-radius: 0
   !important` для всех элементов, включая порталы Base UI. Скругление — это
   чужой стиль, а не деталь.
2. **Один акцент.** Монохром плюс единственный розово-красный. Акцент — для
   интерактива, живого состояния, промпта `$` и `<em>` в заголовке. Статусы и
   ошибки его не берут: смысл несут слово, форма маркера и инверсия.
3. **Hairline вместо тени.** Глубина — разницей поверхностей (`--bg` →
   `--surface` → `--surface-2` → `--surface-3`) и линией 1px. `box-shadow`
   равен `none`, подъём карточки — смена заливки.
4. **Служебный текст — mono-капс.** Номера разделов `[01]`, метки, заголовки
   таблиц, кнопки, навигация: Geist Mono, 10–11px, трекинг `0.08em`, uppercase.
   Основной текст и заголовки — Geist Sans.
5. **Пиксель-арт вместо картинок.** Фотографий и декоративных градиентов нет.
   Фон — дизеринг-сцены на canvas, иконки — битмапы 9×9, знак — кристалл 7×10.
6. **Честные подписи.** «Онлайн», «нет связи», «ждёт привязки» вместо «активен».
   В отчётах — `started_plays`, а не «просмотры»: показ подтверждён, внимание —
   нет.
7. **Движение короткое и необязательное.** Переходы 90–220 мс, появление — на
   2px вверх. При `prefers-reduced-motion` анимации выключаются, а сцена
   остаётся статичным кадром.

| `--text` / `--text-muted` / `--text-subtle` | `#ffffff` / `62%` / `50%` | `#000000` / `#636363` / `#737373` |
| `--primary` / `--primary-hover` | `#ff4f7b` / `#ff9fb2` | `#c2143f` / `#8f0f2f` |
| `--primary-text` / `--primary-soft` / `--primary-border` | `#0a0a0a` / `10%` / `28%` | `#ffffff` / `6%` / `26%` |

| `--label-tracking` / `--density-row` | `0.08em` / `40px` | те же |

Токены объявлены обычными переменными и попадают в Tailwind через
`@theme inline`: значения должны переключаться вместе с классом `.dark`, а
утилиты — оставаться теми же (`bg-surface`, `text-text-muted`,
`border-border-strong`, `text-primary`).

Статусы (`--success`, `--warn`, `--danger`, `--info`) намеренно монохромны в
обеих темах: отдельный оттенок для ошибки конкурировал бы с акцентом.

### Типографика

- **Geist** — текст и заголовки; **Geist Mono** — метки, таблицы, код, числа.
  Оба подключаются через `next/font` с подмножеством `cyrillic`; без него
  русский текст падал бы на системный шрифт.
- Базовый текст: 14px / 1.5, трекинг `-0.006em`.
- `.page-title` — `clamp(1.5rem, 1.15rem + 1.2vw, 1.875rem)`, вес 500,
  трекинг `-0.035em`, `text-wrap: balance`. Один класс на все разделы панели.
- `.section-title` и `.label` — mono-капс 10.5px и 11px с трекингом `0.08em`.
- Таблицы: заголовки колонок — mono-капс 10px; числа — `font-variant-numeric:
  tabular-nums` (`.tnum`).
- `<em>` в заголовке — не курсив, а акцентный цвет.
- Поля ввода на телефоне — 16px, иначе iOS увеличивает страницу при фокусе;
  с `768px` — 14px.

### Темы

- Светлая — базовая (`:root`), тёмная — класс `.dark` на `<html>`.
- По умолчанию тема следует системной; ручной выбор хранится в
  `localStorage['shawty-theme']`.
- Инлайновый скрипт в `<head>` применяет тему до первой отрисовки, поэтому
  тёмная не мигает белым. `theme-color` меняется вместе с темой.
- Переключатель (`ThemeToggle`) нарочно тихий: квадрат с hairline, без
  акцентной заливки.
- Дизеринг-сцена читает `--bg` и `--accent-rgb` из computed style и
  пересчитывает палитру по `MutationObserver` на классе `<html>` — смена темы
  перекрашивает канвас без перезагрузки.

### Фирменная графика

- **Знак** — «ступенчатый кристалл» 7×10 (`MARK`), один SVG-path из единичных
  квадратов, `shape-rendering: crispEdges`, цвет — `currentColor`.
- **Пиксельные иконки** — битмапы 9×9 (`network`, `database`, `gauge`, `panel`,
  `lock`, `code`, `package`, `folder`, `flag`, `table`, `stack`, `spark`).
  Используются там, где иконка — часть бренда или состояния. Функциональные
  действия остаются линейными (`lucide-react`): у пиксельной формы нет
  узнаваемых мелких деталей, на кнопке важнее смысл.
- **Lockup** — знак, слово на акцентной плите и служебный чип. Плита —
  единственное место, где акцент занимает площадь.
- **Дизеринг** (`Dither`, `dither-engine.ts`) — canvas с одним пикселем на
  ячейку и `image-rendering: pixelated`; три тона (фон, смесь акцента, акцент),
  упорядоченный дизеринг по матрице Bayer 4×4, 12 fps. Сцены: `crystals`
  (кристаллы, hero и экраны состояния) и `flow` (полосы света, фоны форм и
  плеера). При `prefers-reduced-motion` — один статичный кадр; вне viewport
  цикл останавливается; `aria-hidden`, потому что сцена декоративна.

### Классы и паттерны

| Класс | Назначение |
|---|---|
| `.card`, `.card-interactive` | Плоская поверхность с hairline; подъём — заливкой, не тенью |
| `.field` | Поле ввода/select: высота 40px, линия `--border-strong`, фокус — акцентная линия |
| `.page-title`, `.section-title`, `.label` | Заголовок страницы, метка раздела, самостоятельная mono-метка |
| `.hairline`, `.row` | Разделитель 1px и строка списка с hover-заливкой |
| `.stack-table` | Таблица, которая по ширине **контейнера** (40rem) сворачивается в карточки; подписи — из `data-label`, первая колонка — `data-primary`, второстепенные — `data-secondary` |
| `.fade-in`, `.stagger`, `.pressable`, `.shimmer` | Появление за 180–220 мс, каскад до 10 строк, нажатие на 1px, мерцание двумя тонами |
| `.dither`, `.player-shell` | Канвас сцены и оболочка экрана телевизора |
| `.landing-*` | Композиция лендинга: рамка, шапка, hero, ячейки, marquee, сцены, финал |

Правила для новой разметки:

- Цвет — только токеном, не hex в разметке; проверять обе темы.
- Акцент — точечно: ссылка, живая метка, выбранный таб, `<em>`. Если акцента
  на экране два, один из них, скорее всего, лишний.
- Радиусы и тени не добавлять даже локально — это ломает систему.
- Ширину проверять у контейнера (`@container`), а не у окна: панель занимает
  часть широкого монитора.
- Новое движение — короткое, с финальным состоянием в SSR и поддержкой
  `prefers-reduced-motion`.

### Лендинг

`/` собирается в `src/widgets/landing/ui/landing-page.tsx` из секций:

`[00]` hero → marquee → `[01]` как это работает → `[02]` синхронизация без
флешек → `[03]` цепочка доставки → `[04]` панель → `[05]` журнал → `[06]`
плеер → `[07]` механизмы → `[08]` сценарии → `[09]` живая сводка сети →
`[10]` тарифы → `[11]` FAQ → CTA-полоса и гигантский вордмарк.

- Рамка `75rem` с вертикальными hairline; sticky-шапка с blur только на
  подложке; на `64rem` навигация скрывается, на `30rem` — сжимаются действия.
- Тексты, тарифы, лимиты и списки — в `src/components/landing/content.ts`,
  а не в JSX.
- Секция `[09]` ходит в `/api/network-stats`; при недоступности API показывает
  состояние «нет данных», а не выдуманные числа.
- Каждая секция подписана `aria-labelledby`, заголовки имеют `id`; у сцен —
  `aria-hidden`, потому что весь смысл лежит рядом обычным слоем.

### Плеер

Экран телевизора — не панель: нет карточек, мелких подписей и hover-состояний.
Фон — near-black, глубину даёт дизеринг, шрифт — системный sans крупнее и
контрастнее (`--font-player`), появление медиа — `steps(6)` за 420 мс. Состояния
(ожидание, привязка, ошибка, нет связи) рисуются тем же языком, что и остальной
продукт.

## Ограничения

- Дизайн-система описана двумя документами: `design.md` — справочник,
  `globals.css` — реализация. При расхождении прав код, а справочник нужно
  поправить тем же изменением.
- Глобальный `border-radius: 0 !important` — сознательная страховка: сторонние
  компоненты приносят свои скругления. Новый компонент с радиусом не «выключит»
  правило, а сломает ожидания.
- Светлая тема проверяется вручную: автотестов на контраст и скриншоты пока нет.
